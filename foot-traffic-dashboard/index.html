資料方法說明：Google Maps Platform 不提供官方即時人流（footfall）API。本儀表板以 Places API (New) 取得展示中心半徑 600 m 內的地點（商場、餐飲、大眾運輸、辦公、休閒）， 以「地點類型權重 × 評論規模 × 各類型時段曲線」建立人流指數模型；熱力圖強度為該時段各地點的相對人流貢獻。 所有數值皆為估算值，適合用於相對比較（時段間、兩地間），非實測人數。 未設定 API 金鑰時顯示模擬資料。若需實測人流，可再串接第三方資料源（如 BestTime、電信人流資料）。

Google Maps API 金鑰

金鑰只儲存在你瀏覽器的 localStorage，不會上傳到任何伺服器。

  1. 到 Google Cloud Console 建立專案並啟用計費
  2. 啟用 Maps JavaScript API、Places API (New)、Geocoding API
  3. 建立 API 金鑰，並以 HTTP referrer 限制網域
